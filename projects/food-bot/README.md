# Food Bot — дневник питания в Telegram

Telegram-бот: пишешь текстом, что съел — он оценивает калории и БЖУ через
локальную модель в LM Studio, ведёт дневник в SQLite и присылает
напоминания про воду и еженедельное взвешивание. Целевые цифры (2350 ккал,
160 г белка) — из плана в `../../health/` (документ «Питание и здоровье»).

## Возможности

- Любое сообщение без команды = запись о еде → оценка ккал/Б/У/Ж от LM Studio.
- `/today` — итоги за сегодня (калории, БЖУ, вода, последний вес).
- `/week` — среднее за 7 дней + динамика веса.
- `/weight 94.2` — записать вес.
- `/water` — отметить стакан воды (тот же счётчик обновляет кнопка под напоминанием).
- Напоминания: вода — 3 раза в день (11:00, 14:30, 18:00 по умолчанию),
  взвешивание — раз в неделю (по умолчанию понедельник, 09:00).

## Установка

1. Установи Python 3.10+ (если ещё не стоит).
2. В этой папке: `start_bot.bat` — он сам создаст `venv` и поставит зависимости
   при первом запуске. Либо вручную:
   ```
   python -m venv venv
   venv\Scripts\activate
   pip install -r requirements.txt
   ```

## Настройка

1. Скопируй `.env.example` в `.env`.
2. Получи токен бота: напиши в Telegram **@BotFather** → `/newbot` →
   следуй инструкциям → вставь полученный токен в `BOT_TOKEN=`.
3. Проверь, что в **LM Studio** запущен локальный сервер (вкладка
   *Local Server* → *Start Server*) и загружена модель. Порт по умолчанию —
   1234, в `.env` он уже прописан (`LMSTUDIO_URL`). Если модель не отвечает —
   в LM Studio на вкладке сервера видно её точное имя; если бот не находит
   модель, впиши это имя в `LMSTUDIO_MODEL`.
4. При желании поменяй целевые калории/белок, время напоминаний, часовой
   пояс — всё в `.env`.

## Запуск

Двойной клик по `start_bot.bat` (окно консоли останется открытым — так
видно логи и ошибки). Чтобы остановить — закрыть окно или Ctrl+C.

## Автозапуск на Windows (чтобы бот работал постоянно, 24/7)

Проще всего — добавить ярлык на `start_bot.bat` в папку автозагрузки:

1. `Win + R` → ввести `shell:startup` → Enter — откроется папка автозагрузки.
2. Скопировать туда ярлык на `start_bot.bat` из этой папки.
3. Бот будет запускаться при каждом включении/входе в Windows.

Минус — при запуске открывается окно консоли. Чтобы бот стартовал незаметно
(без окна), вместо ярлыка на .bat используй ярлык с такой командой:
```
pythonw.exe "D:\AI_Project\projects\food-bot\bot.py"
```
(указав путь к `pythonw.exe` внутри `venv\Scripts\`).

Более надёжный вариант — через Планировщик заданий Windows (Task Scheduler):
создать задачу с триггером «При входе в систему», действие — запуск
`start_bot.bat`, и поставить галку «Выполнять с наивысшими правами» /
«Independently of user logon» при необходимости, чтобы бот пережил
блокировку экрана.

## Ограничения MVP

- Оценка БЖУ зависит от качества ответа локальной модели — это оценка
  «на глаз», не лабораторный анализ. При явно неверном значении запись
  всё равно сохраняется как есть; редактирование задним числом пока не
  реализовано — это можно добавить следующим шагом (команда `/correct`).
- Если LM Studio не запущен — запись о еде сохранится без БЖУ, с пометкой.
- Один файл `food_bot.db` — бэкапы делать вручную (просто скопировать файл).
