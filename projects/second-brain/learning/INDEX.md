# ОБУЧЕНИЕ — карта домена

## Структура

```
learning/
├── INDEX.md              ← ты здесь
├── books/                ← книги, фреймворки, анализ
│   ├── INDEX.md              карта книг по темам
│   └── frameworks/           обобщённые принципы из книг для
│                              принятия решений
└── skills/               ← карта навыков (что учить, что учится)
```

## Как это работает
1. Книги (все 250+) хранятся в [[../../Книги/]] и анализируются проектом [[../../projects/knigi/]]
2. Из книг извлекаются **фреймворки** — обобщённые принципы для принятия решений
3. При выборе между вариантами — агент проверяет frameworks/ и предлагает решение, объясняя «почему так» через книжные принципы
