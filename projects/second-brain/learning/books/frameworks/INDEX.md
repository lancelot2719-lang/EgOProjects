# Фреймворки из книг — для принятия решений

> **Когда использовать:** всегда, когда есть выбор между вариантами или нужен план действий.

## Как работают фреймворки
1. Агент читает эту папку — видит список фреймворков
2. Определяет, какой фреймворк подходит к ситуации
3. Применяет его, объясняя «почему так» через книжный принцип
4. Предлагает альтернативы с оценкой
