```
second-brain/
├── INDEX.md          ← Ты здесь. Полная карта всего второго мозга
├── ai-clone/         ← КТО Я: профиль, стиль, принципы, голос, уроки

│   ├── voice/           тон, стоп-слова

│   └── style/           шаблоны ответов (пусто — по необходимости)

│   ├── goals/           приоритеты и KPI
│   ├── economics/       долги ~1.33M, стратегия погашения
│   └── marketing/       подход к продажам, price_search.py
├── health/           ← ЗДОРОВЬЕ: спорт, питание, сон, биохакинг
├── daily/            ← БЫТ: привычки, покупки, рутина
├── learning/         ← ОБУЧЕНИЕ: книги, курсы, фреймворки
│   ├── books/           250+ книг по 15 темам
│   └── skills/          карта навыков
├── mafia/            ← МАФИЯ: стратегия, анализ, телеграм-датасет
├── projects/         ← ПРОЕКТЫ: карта всех активных проектов
└── tools/            ← ИНСТРУМЕНТЫ: AI-инфра, скрипты, pipeline
```

## Как пользоваться вторым мозгом

1. **Запрос по любой теме** → открой соответствующую папку, прочитай INDEX.md, затем нужный файл
2. **После любого действия** → запиши вывод в feedback/ (ai-clone/feedback/)
3. **После любого решения** → запиши в соответствующую доменную папку
4. **Книжные фреймворки** → при выборе между вариантами проверь learning/books/frameworks/
