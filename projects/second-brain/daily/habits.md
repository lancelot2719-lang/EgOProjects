# Привычки и дисциплина

## Текущие треки
- Спорт: баскетбол 2× / неделя, падел 2× / неделя (см. [[../health/training.md]])
- Сон: в работе (см. [[../health/sleep-guide.md]])
- Финансы: отслеживание долгов (см. [[../business/economics/finance-situation.md]])

## Что встраивается
- Еда с собой на работу (экономия + здоровье)
- Режим сна (циркадные ритмы)
- Регулярная работа со вторым мозгом (ежевечерний апдейт)

## Принцип внедрения (из книг)
По одной привычке за раз, минимум 3 недели на закрепление.
См. [[../learning/books/frameworks/]] — «Атомные привычки»
