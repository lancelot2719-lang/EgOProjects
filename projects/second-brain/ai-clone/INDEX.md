# ai-clone — Карта папок

```
ai-clone/
├── INDEX.md      ← этот файл, карта раздела
├── role.md       ← описание владельца (кто ты, чем занят, ценности)
├── identity/     ← твои личные черты, которые важны для принятия решений
├── voice/        ← как ты говоришь и пишешь (тон, стоп-слова)
├── principles/   ← правила принятия решений (как думать, что проверять)
├── feedback/     ← извлечённые уроки после ошибок агента (что пошло не так, как исправить)
└── style/        ← шаблоны ответов, форматирование, примеры
```

## Назначение
Это цифровая копия твоего мышления. Всё, что агент должен знать о тебе как о личности — хранится здесь. Чем полнее этот раздел, тем точнее агент воспроизводит твой стиль мышления и принятия решений.
