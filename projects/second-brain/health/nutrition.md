# Питание — для энергии и восстановления

> **Цель:** стабильная энергия в течение дня + восстановление после спорта

## Принципы
1. **Белки** — каждый приём пищи (яйца, мясо, рыба, творог, бобовые)
2. **Сложные углеводы** — только утром и днём (гречка, овсянка, цельнозерновой хлеб)
3. **Сахар — минимум.** Сладкое → резкий подъём энергии → спад через 30–40 мин
4. **Вода — 2–2.5 л/день** (не чай/кофе, а именно вода)
5. **Последний приём еды** — за 3 часа до сна

## Расписание
| Время | Что | Комментарий |
|-------|-----|------------|
| 07:30 | Завтрак | Белки + сложные углеводы (омлет + овсянка/гречка) |
| 10:00 | Перекус | Орехи (30 г), яблоко |
| 13:00 | Обед | Белки + овощи. Без сахара/десерта |
| 16:00 | Перекус | Творог, яйцо, или протеин |
| 19:00 | Ужин | Лёгкий: рыба/курица + овощи. Без углеводов |
| 22:00 | — | Ничего не есть |

## Типовой набор продуктов для закупки
- **Белки:** яйца, куриное филе, рыба/консервы, творог, греческий йогурт, бобовые
- **Углеводы:** овсянка, гречка, цельнозерновой хлеб
- **Жиры:** орехи (грецкие, миндаль), оливковое масло
- **Овощи/фрукты:** огурцы, помидоры, капуста, яблоки, бананы (до/после тренировки)
