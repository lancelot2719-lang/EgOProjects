# Pipeline сделки — пошагово

> **Цель:** не терять сделки на этапах. Проверять каждый шаг.

## Этапы продажи

### 1. Поиск / входящий контакт
**Что делаю:** принимаю заявку или нахожу клиента
**Продукт:** любой
**Чек-лист:**
- [ ] Записал контакт в CRM / таблицу
- [ ] Понял: это разовая покупка или потенциально постоянный клиент?
- [ ] Назначил звонок/встречу в течение 24ч

### 2. Discovery (выявление потребности)
**Что делаю:** задаю вопросы, молчу, слушаю. Не продаю!
**Ключевой навык:** 80% времени говорит клиент, 20% — я
**Чек-лист:**
- [ ] Какая задача стоит?
- [ ] Что уже пробовали? Не сработало?
- [ ] Кто принимает решение?
- [ ] Бюджет определён?
- [ ] Сроки?
**Результат:** понимаю, что нужно клиенту. Если не понял — не перехожу к КП.

### 3. Коммерческое предложение
**Что делаю:** готовлю решение под конкретную боль (не «вот наш прайс»)
**Чек-лист:**
- [ ] В КП отражена потребность клиента (не просто список товаров)
- [ ] Есть 2–3 варианта (дёшево/средне/дорого)
- [ ] Есть срок действия КП
- [ ] Отправил и назначил дату ответа

### 4. Обработка возражений
**Типовые возражения:** «дорого», «подумаем», «уже есть поставщик», «начальник не одобрит»
**Как отвечаю:** не спорю → соглашаюсь → задаю вопрос → возвращаю к потребности
**Фреймворк:** см. [[../../learning/books/frameworks/objection-handling.md]]

### 5. Закрытие
**Что делаю:** беру обязательство. «Когда начинаем?», «Какое решение выбираете?»
**Чек-лист:**
- [ ] Назвал конкретную дату начала
- [ ] Договорились о следующих шагах
- [ ] Отправил договор/счёт

### 6. Пост-продажа
**Что делаю:** проверяю, что всё работает. Запрашиваю рекомендации.
**Цель:** повторная продажа или рекомендация

### 7. Реактивация базы (добавлено 05.08.2026)
**Проблема:** ~100 тёплых контактов в базе, но контакты, которые сказали «сейчас ничего нет», выпадают из работы — иногда на месяцы. Решение о том, что «тема закрыта», принимается по умолчанию, без проверки.
**Что делаю (новое правило):**
- [ ] Клиент сказал «пока нет» → не удаляю из активной работы, ставлю следующее касание через 4–6 недель
- [ ] Касание — не «продажа в лоб», а короткий повод: новость по рынку, апдейт по товару, вопрос в тему их бизнеса
- [ ] Если клиент кажется «маленьким» — прежде чем отсекать, прикинуть в цифрах: сколько времени реально займёт vs какой чек. Не решать на глаз (см. [[sales-approach.md]] — «противоречие» с [[../../learning/books/frameworks/sales-methodology.md]])
**Источник:** правило появилось из разбора собственного паттерна, не из книги — записать как личный вывод, не путать с книжным фреймворком
