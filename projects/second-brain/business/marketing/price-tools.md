# Инструменты мониторинга цен

> **Контекст:** [[sales-approach.md]] — экспертный подход требует знания рынка

## price_search.py
- **Назначение:** Личный мониторинг цен на IT-железо (ОЗУ DIMM)
- **Целевые магазины:** DNS, Onlinetrade, Ситилинк, Комус, X-com shop
- **Статус:** Нерабочий — селекторы устарели, требуется рефакторинг
- **Путь:** `D:\AI_Project\price_search.py`

## Для чего используется
- Понимать текущий рынок, чтобы аргументировать предложение клиенту
- Не для скидывания клиентам, а для личной подготовки к переговорам
- Быстрая проверка: адекватна ли наша цена?

## Планы по доработке
- Ожидает рефакторинга (обновить селекторы под текущую вёрстку магазинов)
- Возможно расширение на серверное оборудование (не только ОЗУ)
