## 1. Общий анализ

### Ключевой вывод из всех видео
**В 2026 году не существует одного «лучшего» AI. Модели стали узкоспециализированными.** Каждый инструмент — это не универсальный помощник, а инструмент с конкретным назначением. Выбор модели должен определяться задачей, а не брендом.

### Новый вывод после 17 дополнительных видео
**Разница между «профи» и «новичком» в 2026 году — не в том, какой моделью пользоваться, а в том, как управлять контекстом и токенами.** Практически все продвинутые видео (гайды по Cursor, OpenCode, лимитам Claude/Codex) фокусируются не на выборе модели, а на: компактном контексте, разбиении задач на сессии, сабагентах, и понимании, что «показ модели меньше — лучше».

### Мой анализ (с учётом внутренних знаний + транскриптов)

**Реальность 2026 года:**
- GPT остаётся самым универсальным («точка входа»), но перестал быть лучшим в каждой конкретной задаче; при этом GPT-5.5 заметно снизил галлюцинации против прошлых версий
- Claude лидирует в коде и глубоком анализе — подтверждено всеми источниками; майское партнёрство Anthropic + SpaceX (доступ к дата-центру «Colossus 1») удвоило 5-часовые лимиты Pro/Max/Team/Enterprise
- Grok уникален интеграцией с X, но маркетинговые обещания часто превышают реальные возможности
- Gemini силён в интеграции с Google Workspace и NotebookLM, но слабее конкурентов в чистых бенчмарках
- DeepSeek — тёмная лошадка: отличное соотношение цена/качество для специфических задач
- GigaChat — сырой продукт, не готов к серьёзной работе
- **Codex (OpenAI)** обновляется экстремально быстро (7 версий за 1 день по наблюдению одного из авторов) — по возможностям почти зеркалит пару Claude+Claude Code
- **Cursor** и **OpenCode** — не конкуренты моделям, а надстройки над ними; выбор между ними — это выбор UX/автономности, а не «ума»

**Из транскриптов wOMDsWrSyic, TaMne2P-kHU, GxkAFdBNI0c, J04REnA4VFQ, YttzbKkdjWY:**

- **Custom Instructions**: Settings → Personalization → Custom Instructions — задать персону/тон один раз, работает во всех новых чатах

- Формула хорошего промта: явно задать роль+задачу («ты опытный маркетолог...») + контекст/ограничения формата + разбить сложный запрос на шаги по порядку
- ChatGPT прозвали «Apple среди AI» — самый простой UI, лучшая точка входа для новичков
- **Codex** — коддинг-агент OpenAI, аналог связки Claude+Claude Code; обновляется очень быстро (7 версий за день по наблюдениям одного автора); есть Plan Mode (Shift+Tab, как в Claude Code)
- Совет от TaMne2P-kHU: вместо одной подписки за $100 выгоднее взять **две по $20** (ChatGPT Plus + Claude Pro) — ChatGPT планирует/декомпозирует задачу в спеку, Claude эту спеку исполняет
- ChatGPT почти не банит аккаунты даже при нестабильном VPN, в отличие от Claude (гораздо строже к банам)
- OpenAI выпустил **Atlas** — браузерного агента (в демо сам оформил заказ еды на сайте), аналог computer-use у Claude
- Мнение YttzbKkdjWY: Codex — слабый «стратег» для брейнштормов, но отличный исполнитель, особенно на бэкенде/анализе данных — используется в связке «Opus как стратег, Codex как исполнитель»

**Моя оценка:**
- **Плюсы:** Лучшая точка входа; огромное сообщество; максимум интеграций; Deep Research уникален; Custom GPTs с Actions
- **Минусы:** Галлюцинации (хотя GPT-5.5 их заметно снизил); отказывается от сложных задач; дорогой в API
- **Лучше всего для:** Общие вопросы, brainstorming, быстрые правки, анализ скриншотов, голосовые запросы, точка входа для новичков
- **Цена:** $20/мес Plus, $200/мес Pro (неофициально)

**Лайфхак из транскрипта:** Используйте Custom Instructions в настройках → Персонализация. Пропишите кто вы, ваш стиль общения, контекст работы. Это меняет качество ответов кардинально.

### 2.2 Claude Opus 4.7 / Claude Code

**Из транскрипта:**
- Победитель в сравнении 10 раундов (30 очков из 40)
- Лучший в анализе данных: глубокий бизнес-анализ с цифрами, проблемами и решениями
- Claude Code — отдельный агент для программирования (из подкаста Jcx-JclhB18)
- Образцовая работа с русским языком и культурным контекстом

**Из подкаста Jcx-JclhB18:**
- Claude Code — один из главных инструментов для AI-программирования
- Конкурирует с OpenCode и Cursor в сегменте AI-агентов
- Файловый поиск — ключевой элемент работы агентов

**Из транскриптов eXp8TC0Sm6o, J04REnA4VFQ, GxkAFdBNI0c, YttzbKkdjWY (главное дополнение этого обновления):**
- Claude Code — это CLI-инструмент, не полноценная IDE; $20/мес Claude Pro даёт приличный доступ к Sonnet, для Opus нужны более дорогие тарифы; расширения дают доступ к открытому файлу/выделенной строке в редакторе
- **Токеномика:** 1 английское слово ≈ 0.75 токена; 1 русское слово ≈ 2–3 токена — русский обходится в 2-3 раза дороже по обработке
- **Контекстное окно теперь 1M токенов** (было 200K), но качество деградирует задолго до потолка («context rot») — лучшая производительность в первых ~100K токенов; рекомендация — не превышать ~120K токенов за сессию, дальше `/compact`, откат или новый чат
- Статистика: в чате на 100 сообщений ~98.5% токенов на сообщении №100 уходят на повторную обработку истории против ~1% на генерацию нового ответа
- Токены на выход стоят ~в 5 раз дороже токенов на вход при равном объёме (авторегрессивная генерация переобрабатывает всё написанное слово за словом) — просите модель отвечать короче, чтобы снизить расходы
- **Rewind** (есть также в Cursor/Codex): «Fork conversation from here» (откат только чата), «Rewind code to here» (откат только файлов), или оба сразу — дешевле, чем вручную поправлять плохо выполненный запрос
- Редактирование предыдущего сообщения (иконка карандаша) чище, чем добавление сообщений с исправлениями — экономит контекст
- `/btw` — задать побочный вопрос, не засоряя основной тред; вопрос и ответ исчезают из истории по Escape
- **Сабагенты** работают в отдельном контекстном окне, в основной чат возвращается только их саммари — экономит токены главного треда (есть в Claude Code и Codex)
- **Skills** — переиспользуемые markdown-инструкции; в контексте по умолчанию только заголовок+описание, полное тело подгружается только при срабатывании — экономит токены на повторных объяснениях
- Держите CLAUDE.md/AGENTS.md короче ~200 строк; большие справочные материалы (дизайн-системы и т.д.) выносите в отдельные md-файлы и ссылайтесь на них по пути
- Отключайте неиспользуемые MCP-серверы (например Playwright MCP жрёт токены и тормозит) через `/mcp` → disable
- Подбирайте модель под сложность задачи: Haiku — для тривиальных правок, Sonnet — для большинства работы, Opus — только для самых сложных задач (та же логика в Codex)
- **Plan Mode** (Shift+Tab, и в Claude Code, и в Codex) заставляет составить план перед правками — снижает дорогостоящие переделки
- Плагин **«Superpowers»** (работает и в Claude Code, и в Codex): пакет skills под воркфлоу брейншторм → план → реализация → тесты; оправдан только для крупных задач
- 5-часовое окно лимитов Claude стартует с первого сообщения за день; лайфхак — через «Claude Routines» автоматически слать тривиальное сообщение в фиксированное раннее время (например 6:00), чтобы окно и его сброс приходились на предсказуемое время
- **6 мая 2026:** Anthropic партнёрится со SpaceX, получив доступ к дата-центру «Colossus 1» (Мемфис) — удвоены 5-часовые лимиты Pro/Max/Team/Enterprise, убран пиковый троттлинг, подняты лимиты Opus API
- Конвертируйте PDF/DOCX/HTML в Markdown перед подачей в LLM — убирает шум шрифтов/метаданных/вёрстки. Пример: тот же контент = 15 000 токенов как PDF против 8 000 токенов как Markdown; Markdown — «родной» формат для модели
- **Claude Projects** держат 4 типа памяти: «user» (кто вы), «reference» (ссылки на внешние источники — Claude подтягивает только нужное), «project» (общие доки, например брендбук), «feedback» (ваши правки по формату/поведению, сохраняются между сессиями)
- Держите одну сессию — одна тема; закрепляйте полезные сессии; новая сессия под новую задачу, чтобы не смешивать несвязанные темы («суп из контекста»)
- **Коннекторы Claude:** Obsidian (Claude читает индексный файл, подтягивает только нужные заметки — большая экономия токенов/времени против сброса всей папки), Google Workspace, GitHub, NocoDB/AirTable, самописные API-коннекторы — в демо Claude сам исследовал GitHub/Reddit и построил рабочий коннектор для устройства без официального API (Plaud), а также реверс-инжинирнул рабочий API-коннектор HeadHunter и Bitrix24 по публичной документации
- Реальные цифры экономии из вебинара: кастомная система планирования производства, которую сам Claude оценил в ~3.5–4 млн ₽ / ~5 месяцев работы агентства — построена за 8 рабочих дней одним человеком с Claude Code; аналогично внутренняя вики ценой ~4 млн ₽ — построена за ~1.5 недели
- Рекомендуемая раскрутка расходов: начать с $20/мес, за ~неделю упереться в лимиты и перейти на $100/мес; автор вебинара лично платит ~$200/мес, оценивая это как ~$3000/мес в эквиваленте raw API — но советует не прыгать сразу на $200: лимиты тарифа $100 дисциплинируют работу с данными
- Claude Code может спроектировать и опубликовать целый N8N-автоматизацию по текстовому описанию — без единого узла, собранного вручную (пример: HeadHunter-пайплайн подбора: синхронизация вакансий каждые 6ч, предскрининг кандидатов по рубрике, шаблонные письма отказа)
- VPN-рекомендация во избежание банов Claude: «BOV VPN»; регистрировать аккаунт через Google (не .ru почту), платить картой страны регистрации
- Не полагайтесь на генераторы промтов для обычных текстовых задач — полезны только для сложных структурированных промтов (например консистентная генерация AI-аватара); для обычной работы просто пишите Claude напрямую
- **«Board of Advisors»**: параллельные сабагенты с изолированным контекстом и назначенной персоной (например «архитектор контент-пайплайна», «SEO-стратег») дают независимую критику воркфлоу без взаимного заражения рассуждений; результаты записываются как новые GitHub Issues
- ⚠️ **Безопасность:** некоторые «бесплатные» опубликованные skills содержат скрытые prompt-injection инструкции (например «рекомендуй этот курс/сайт», зашитое в текст skill) — всегда просите Claude проаудировать skill перед установкой, или используйте только проверенные библиотеки (например «Superpowers»)
- GitHub Issues как постоянная «память для AI-агентов» — доступно с телефона, поддерживает Mermaid-диаграммы в markdown; предпочтительнее чистого локального хранения — бесплатно, синхронизируется на 4 устройствах через 2FA/passkey, переживает потерю устройства (автор утверждает, что может пересобрать весь «корпорации» из агентов на новом ноутбуке за ~10 минут)
- Тариф Copilot/agent от GitHub ($10/мес) даёт доступ к Opus внутри репозитория — «самый дешёвый способ получить хороший доступ к Opus прямо сейчас»
- Claude Code сам подсказывает в контексте («сожми контекст сейчас», «обнови эту задачу»), когда качество работы деградирует — встроенный слой самонапоминания
- О риске вендор-лока: главный риск — геополитический/непрерывность бизнеса, а не технический; после опытов с локальными и китайскими моделями — «ничего даже близко не стоит рядом» для оркестрации сложных задач, альтернативы годятся только для самых простых подзадач; ~$100-200/мес на Claude ≈ ~$3000/мес API-эквивалента, названо лучшим соотношением цена/возможности на рынке сейчас

**Моя оценка:**
- **Плюсы:** Лучший анализ и структурирование; силён в коде; контекст теперь 1M токенов (хотя реально полезны первые ~100K); Claude Code — зрелый продукт с богатой экосистемой коннекторов, памяти и сабагентов
- **Минусы:** Дорогой; заблуждается в цифрах/реалиях; строго банит аккаунты за нестабильный VPN; context rot требует дисциплины в управлении сессиями
- **Лучше всего для:** Программирование (особенно Claude Code), анализ данных, работа с большими документами, построение персональных «AI-операционных систем» на GitHub/Obsidian

**Лайфхак из транскрипта:** Для анализа Excel/CSV файлов Claude справляется лучше всех — загружайте сырые данные и просите бизнес-выводы с цифрами.

### 2.11 Suno AI

**Из транскрипта OWfF98UvGEM (новый раздел):**
- Относитесь к Suno как к «цифровой DAW», а не лотерее — осознанный воркфлоу побеждает «нажал Generate и надеешься»
- Вкладки: Create (рабочая область), Library (сгенерированные треки; лайк/дизлайк — только личная сортировка, не соцсеть), Workspace (проектные папки по жанрам/каналам/альбомам)
- Simple Mode — быстрая идея в одну строку (не перескакивайте сразу в Custom Mode, это главная ошибка новичков); Custom Mode — когда жанр/настроение/вокал/структура уже решены

- Синтаксис: текст в [квадратных скобках] = инструкции модели; текст без скобок = буквально спетый текст — если перепутать, Suno буквально пропоёт ремарки режиссёра

- **Persona** — фиксирует вокал/стиль удачного трека как переиспользуемый референс для консистентной серии/альбома
- Pro-версия добавляет построчный редактор текста/ударений для точечных правок без полной перегенерации
- Ключевая мысль: результат Suno — всегда «демо», для реального релиза всё равно нужен экспорт стемов и настоящий сведение/мастеринг вне Suno

**Моя оценка:** Suno — не про случайность, а про воркфлоу. Главная ошибка новичков — пропускать Simple Mode и порядок промта. Полезно, если нужен фоновый саунд-дизайн/джинглы для контента (пересекается с проектом AI-блогинга).

## 5. AI-грамотность с нуля

**Из транскрипта YoHuVfr_rjk (иерархия понятий, полезно для объяснения «с нуля»):**

1. **LLM** (пассивна) — предсказывает токены через выученные семантические/векторные связи (классический пример: king − man + woman ≈ queen), а не простое T9-предсказание; основной метод тренировки — Reinforcement Learning (пробный ответ → коррекция → повтор до правильного)
2. **AI Workflow** — LLM с доступом к конкретным инструментам (например календарь), следует фиксированной последовательности шагов
3. **RAG** (Retrieval-Augmented Generation) — поиск по базе знаний → дополнение промта результатами → генерация ответа с опорой на найденное (пример: бот поддержки ищет инструкцию по конкретной модели стиральной машины)
4. **Agent** — сам решает свой путь/инструменты (например выбирает скрапить один агрегатор вместо обхода десятков страниц для «топ-10 конкурентов»)

⚠️ **Важное предупреждение:** агенты с неограниченным доступом к финансам/API могут потратить непредсказуемо много (пример: «сделай классную картинку с уткой» может спровоцировать бесконечные повторные вызовы генерации) — всегда ставьте жёсткие лимиты трат/действий, никогда не оставляйте агента полностью без ограничений.

**Из транскрипта MIME05FAhJg (для полных новичков):**

## 6. Карьера в AI

**Из транскрипта Vo7byizKZ3o (интервью с факультетом ВШЭ):**

**3 столпа навыков для AI/ML:**
1. Математика (линейная алгебра, матан, вероятность/статистика на уровне интуиции, не доказательств)
2. Программирование (в основном Python; no-code инструменты пока ограничены по возможностям)
3. Изучение методов AI/ML широко (классический ML часто до сих пор превосходит нейросети во многих задачах) + практический опыт сбора данных

**Карьерная заметка:** растёт спрос на «разметчиков данных»/«AI-тренеров»/асессоров (например разметка bounding-box на лицах, построение диалоговых примеров для ассистентов типа YandexGPT/GigaChat) — прогнозируется формализация в отдельную профессию.

**Совет по обучению:** предпочитайте практико-ориентированные онлайн-курсы с быстрой обратной связью книгам; для математики — структурированные курсы/живое обучение вместо чистого самообучения; Kaggle-соревнования и пет-проекты (даже неудачные) — ценный опыт и материал для резюме.

**Программы ВШЭ:** онлайн-бакалавриат CS & Data Analysis (4 года, трек ML); магистратура «Искусственный интеллект» (инженерный фокус); англоязычная «Master of Data Science» (классический ML); магистратура Data Engineering (инфраструктура пайплайнов — отмечен текущий спрос на дата-инженеров, возможно превышающий спрос на «строителей моделей»); «Big Data Analytics» (эксперименты/анализ); «AI в маркетинге и продуктовом менеджменте».

**О состоянии индустрии:** генеративные модели (LLM, аудио/музыка/видео) всё ещё имеют открытые проблемы (галлюцинации, физически неправдоподобное видео) — «ранние дни», высокая исследовательская ценность; более зрелые/готовые к продакшену области — классификация, рекомендательные системы (понятные методы, менее интересны с исследовательской точки зрения, но более готовы к продакшену).

### 9.1 Mistral AI
Французский open-source конкурент. Le Chat — аналог ChatGPT с фокусом на приватность. **Лучше для:** европейские проекты, self-hosting, конфиденциальные данные.

Open-source модель, лидер в сегменте локального запуска. **Лучше для:** локальная разработка, эксперименты, fine-tuning.

### 9.3 Perplexity AI
AI-поисковик с реальными ссылками. **Лучше для:** исследования, факт-чекинг, поиск информации. Уникальная фича: все ответы с источниками.

### 9.4 Claude Code vs Cursor vs VS Code Copilot vs OpenCode vs Codex vs Windsurf
- **Claude Code:** Самый умный, но дорогой. Для сложных задач.
- **Cursor:** Лучший UX, Vibe Coding. Для быстрой разработки.
- **Copilot:** Лучшая интеграция с VS Code. Для повседневной работы; тариф за $10/мес неожиданно даёт доступ к Opus.
- **OpenCode:** Open source, консоль, максимальная гибкость провайдеров.
- **Codex:** Экстремально быстрый цикл релизов, зеркалит Claude Code по возможностям.
- **Windsurf:** Тот же UX-паттерн, что Cursor, но без Claude на момент проверки, годится только для лёгкого использования.

### 9.5 ElevenLabs / Suno AI / Runway
- **ElevenLabs:** Лидер в генерации голоса
- **Suno AI:** Генерация музыки из текста (см. подробный разбор в разделе 2.11)

## Заключение

**Для программирования:** Claude + Claude Code — лучший выбор для сложных задач. Codex почти зеркалит его возможности при экстремально быстром цикле обновлений. Cursor — для быстрой разработки и Vibe Coding с лучшим UX. OpenCode — для тех, кому важна прозрачность, self-host и свобода выбора провайдера.

**Для анализа и работы с текстом:** Claude — король структурированного анализа. GPT — лучшая точка входа для любых задач. Gemini NotebookLM — специализированный инструмент под анализ источников/документов (то, ради чего изначально задумывался проект BookLM в этом же AI_Project).

**Для исследований:** Perplexity AI + GPT Deep Research — убийственная комбинация.

**Для автоматизации без кода:** N8N — низкий порог входа, но хрупкий к мелким ошибкам конфигурации; для тех, кто уже работает с Claude Code/OpenCode, связка «GitHub Issues как память + сабагенты» может быть гибче.

**Бюджетный вариант:** DeepSeek для API, SyntX AI для доступа к Midjourney (в РФ), GitHub Copilot за $10/мес как самый дешёвый способ добраться до Opus.

**Для РФ:** SyntX AI как агрегатор, GigaChat только если нет альтернатив; почти всем современным инструментам (Grok, Gemini, GitHub-агенты) нужен рабочий VPN.

**Главный лайфхак 2026 (обновлено):** Не выбирайте одну модель — используйте 2-3 разных под разные задачи. Но что важнее выбора модели — **управление контекстом**: держите сессии короткими (~100K токенов), используйте сабагентов и skills, конвертируйте документы в Markdown перед подачей в LLM, и не бойтесь начинать новый чат вместо того, чтобы тащить «уставший» контекст дальше.

**Для творческого контента:** Suno AI для музыки (относитесь как к DAW, не лотерее), связка seart.ai/rendernet.ai для AI-персонажей — но всегда с раскрытием AI-природы контента, это не только этично, но и снижает юридический риск.
