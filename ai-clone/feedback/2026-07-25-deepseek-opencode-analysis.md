## 2. Паттерны и проблемы

### 2.1 Дублирование «Системной инструкции»
6 из 18 диалогов начинаются с **одного и того же** системного промпта (роль, многоязычный поиск, древо мыслей, и т.д.). Это:
- ✅ Показывает: промпт рождался итеративно в DeepSeek, затем перенесён в AGENTS.md
- ❌ Потеря ~2000 токенов на каждый разговор
- ❌ DeepSeek не сохраняет системный промпт между сессиями — приходится вставлять вручную

**Решение**: В OpenCode системная инструкция подхватывается из AGENTS.md автоматически.

### 2.2 Глубина vs Скорость
- **deepseek-reasoner** выдавал качественные, глубокие ответы (10-11 сообщений на диалог)
- **OpenCode + Qwen 3.5 local** — значительно слабее reasoning-модели
- ❌ **Qwen 3.5 (~7B)** не тянет сложные задачи, для которых использовался DeepSeek

### 2.3 AGENTS.md — главный тормоз
235 строк, из которых критически важны ~40. Проблемные секции:
- **Секция 3 (Многоязычный поиск)**: требует перевода на 2-5 языков — для 90% запросов не нужно
- **Секция 9 (Формат ответа)**: 12 обязательных блоков — генерируется огромный шаблон на каждый ответ
- **Секция 4 (Древо мыслей)**: дублирует CoT, удваивает объём
- **Секция 6 (Самопроверка 3 этапа)**: A → B → C — каждый ответ проверяется трижды
- **Секция 14 (Восстановление Windows)**: НЕ ОТНОСИТСЯ к работе AI — чисто справочная

### 2.4 Разрыв между DeepSeek и OpenCode
- Глубокие аналитические задачи → DeepSeek (reasoner)
- Текущие задачи/код → OpenCode (qwen3.5)
- ❌ Нет синхронизации контекста между ними
- ❌ Нет RAG: second-brain не индексирован, каждый раз читается вручную

## 3. Что можно улучшить

### 3.1 AGENTS.md — сократить в 2-3 раза
Убрать или вынести:
- Многоязычный поиск → только по необходимости
- Самопроверку A/B/C → оставить однократную
- Формат ответа → убрать жёсткий шаблон, оставить структуру
- Восстановление Windows → вынести в отдельный .md
- Древо мыслей → объединить с CoT

Оставить обязательно:
- Роль и принципы (секция 1)
- Маршрутизацию second-brain (секция 15)
- Анти-галлюцинации (секция 12)

### 3.2 OpenCode — переключить модель
- **Qwen 3.5 (~7B)** — для быстрых запросов и кода
- **DeepSeek-reasoner** (через Ollama или API) — для аналитики
- Либо настроить subagent: быстрый Qwen + глубокий DeepSeek

### 3.3 OpenCode — подключить RAG для second-brain
Файлы второй мозг лежат в MD, но не индексированы. Решение:
- `opencode rag add --path projects/second-brain/`
- Или кастомная команда для подгрузки контекста

### 3.4 Перестать дублировать промпты
Не вставлять «Системную инструкцию» в тело запроса — OpenCode сам читает AGENTS.md

### 3.5 Единая точка входа
Сделать подсказку/алиас: "глубокий анализ → DeepSeek, быстрый ответ → OpenCode"
