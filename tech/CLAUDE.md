# Tech

## Назначение
Технические утилиты, скрипты, тулы

## Содержимое
- Скрипты Python для работы с БД, миграции, анализа
- `opencode-parser-main/` — кастомный парсер для OpenCode
- `opencode-projects.ps1` — алиасы ocp/oca
- Инструменты для работы с Chrome, бекапами, сетью

## Заметки
Скрипты запускать через `python script.py` из PowerShell или cmd.
