## Итоговые рекомендации

### Для кодинга (замена Claude Code):

1. **DeepSeek V4-Flash** (сейчас в OpenCode) — **бесплатно**, без VPN, без лимитов, 1M контекст
2. **DeepSeek V4-Pro** — если нужно качество выше, ~$0.87/1M out (в 30× дешевле Claude)
3. **Qwen 3.7 Max** — альтернатива через Aliyun, ~$3.75/1M out, фронтовое качество

### Если принципиально нужен Claude:

→ **provod.ai** — платишь рублями, цены 1:1, Claude Code переключается сменой `baseURL`

### Для исследований / поиска:

→ **Perplexity** — бесплатно без лимита (базовый), Pro $20/мес (через прокси-карту)

### Чего стоит избегать:

- **YandexGPT / GigaChat** — сильно отстают по качеству кода и рассуждений
- **Прямая оплата Claude/GPT** — требуется VPN + иностранная карта + иностранный номер, риск бана
