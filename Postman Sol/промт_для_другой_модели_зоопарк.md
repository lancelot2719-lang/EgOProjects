Ты делаешь разбор нон-фикшн книги для личной базы знаний. Книга: Татьяна Мужицкая (сборник статей) —
«Зоопарк в твоей голове. 25 психологических синдромов, которые мешают нам жить».

ВАЖНО про исходный текст: приложенный файл — это НЕ полная книга, а ознакомительный фрагмент
(~136 тыс. знаков). В нём полностью представлены только первые 5 статей из 25 заявленных
(синдром самозванца, синдром уточки, синдром спасателя, синдром отложенной жизни, синдром
эмоционального выгорания), причём последняя из них обрывается на полуслове. Остальные ~20
синдромов упоминаются только в оглавлении/вступлении, но в тексте их разборов нет. Учитывай
это: не придумывай содержание отсутствующих глав и явно отметь неполноту текста там, где это
важно для читателя разбора.

Текст книги: [ВСТАВЬ СЮДА ПОЛНЫЙ ТЕКСТ ФАЙЛА С КНИГОЙ]

Напиши разбор на РУССКОМ языке строго по следующему шаблону (используй именно эти
заголовки как markdown H2 `##`):

## Общие сведения
(автор, оригинальное название, год, жанр, объём/статус — 2-4 строки)

## О чём книга
(2-4 абзаца: центральная идея, о чём книга в целом)

## Структура
(как книга организована — главы/части, логика изложения; для этой книги — перечисли
синдромы/«зверей», которые разбирает автор)

## Ключевые идеи
(5-10 пунктов с содержательным раскрытием каждой идеи, не просто заголовки)

## Сильные цитаты
(3-6 дословных цитат из текста — только то, что реально есть в тексте, не выдумывай)

## Конкретные действия
(конкретные практические шаги/упражнения, которые читатель может применить)

## Критика и ограничения
(слабые места книги, спорные утверждения, ограничения применимости — честно и по
существу; для популярной психологии отдельно отметь: есть ли научная база у
описанных «синдромов» или это авторские метафоры, риск самодиагностики)

## Кому читать
(для какой аудитории книга полезна, кому не подойдёт)

## Связь с другими книгами
(с какими другими известными книгами по психологии/саморазвитию эта книга
перекликается или спорит — используй общие знания)

Пиши содержательно и по существу, не воду. Финальный результат — только сам
markdown-документ с этими разделами (без преамбулы вроде "вот разбор"), начни с
`# Татьяна Мужицкая — «Зоопарк в твоей голове»`.
