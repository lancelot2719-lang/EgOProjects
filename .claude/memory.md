# Память Claude Code — назначение папок

Все заметки и файлы — в `projects/second-brain/` по доменам.

## Куда писать

| Действие | Куда |
|----------|------|
| После ответа/действия — извлечённый урок | `ai-clone/feedback/` |
| Настройка тона перед текстом от имени пользователя | `ai-clone/voice/` |
| Шаблон перед документом/письмом | `ai-clone/style/` |
| Правило принятия решений | `ai-clone/principles/` |
| Гипотеза подтверждена данными | в доменную папку по теме |
| Новая идея проекта | `projects/` |
| Заметка по книге/курсу | `learning/` |
| Данные по продажам/клиентам | `business/` |
| Данные по здоровью/сну/тренировкам | `health/` |
| Бытовые заметки, привычки, покупки | `daily/` |
| Заметки по мафии | `mafia/` |
| Заметки по AI-инструментам | `tools/` |

## Правила

1. В начале каждой сессии — читай `ai-clone/role.md`
2. По теме запроса — читай релевантную папку из second-brain
3. При выборе между вариантами — проверь `ai-clone/principles/`, `ai-clone/voice/`, `learning/books/frameworks/`
4. После каждого действия — запиши вывод в `ai-clone/feedback/`
5. Если решение/гипотеза подтверждена — запиши в доменную папку
