## Как работает

1. **Chunking** — книги режутся на чанки по 500 токенов

3. **Извлечение сущностей** — Ollama (Mistral 7B) извлекает из каждого чанка: имя, тип (автор/метод/концепция/книга/принцип/инструмент), описание

5. **Генерация HTML** — D3.js force-layout граф с легендой, фильтром по типу, подсветкой соседей, золотым выделением выбранного узла
