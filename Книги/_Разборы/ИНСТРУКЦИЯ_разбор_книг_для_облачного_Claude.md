# Инструкция: как делать разборы книг (для облачной версии Claude)

Составлено 27.09.2026 по итогам рабочего чата. Это полное описание процесса: откуда брать книги, как проверять источник и полноту, как писать разбор, как проверять цитаты и как отмечать результат в трекере. Выполняй по шагам, ничего не пропуская.

---

## 1. Что это за проект и где что лежит

Пользователь собирает библиотеку структурированных разборов нон-фикшн книг на русском языке, по разделам (Финансы, Развитие, Психология, Продажи, Общение, Тайм-менеджмент, Бизнес и др.).

- Корневая папка: `D:\AI_Project\Книги`
- Книги лежат по папкам разделов: `Финансы`, `Развитие`, `Психология`, `Мышление, привычки, навыки`, `Общение, красноречие, голос`, `Продажи` и т. д. Одна книга может лежать не в «своей» папке — ищи по названию и автору.
- Готовые разборы: `D:\AI_Project\Книги\_Разборы\готовые_разборы\`
- Трекер (главный рабочий файл): `D:\AI_Project\Книги\Рейтинг книг по темам — сверка 08.09.2026.xlsx`
  - листы по разделам («Финансы», «Развитие», «Психология»…), лист «Обзор» (счётчики), лист «Примечания (сверка 08.09.2026)» (журнал изменений по датам);
  - колонки листа раздела: № / Приоритет / Статус (Есть/Нет) / Книга / Автор / Почему / комментарий / **Разбор** / Изначальный формат.

Работа идёт **батчами по ~8 книг**. После каждого батча — короткий отчёт пользователю: что разобрано, что не полное, что заблокировано, что требует его решения.

## 2. Правило легальности источника (действует всегда, без исключений)

1. **Файлы с хэш-паттерном в имени** — `Автор_Название.ХЭШ6.ЦИФРЫ.ext`, например `Grant_Podumayte-eshche-raz….qEuXZQ.640589.txt` — считаются неавторизованным источником. Их **содержимое не используется** для разбора, пока пользователь явно не подтвердит легальность **конкретного** файла. Одно подтверждение не распространяется на другие файлы.
   - Исключение: если рядом есть файл с чистым именем, **побайтно идентичный** (проверка по MD5), — его можно использовать без подтверждения.
   - Уже подтверждены пользователем (можно использовать): Фрайд/Хенссон, Фридман «Пожиратели времени», Моран/Леннингтон, Феррис, Джонсон, Харфорд «Хаос», Кабейн «Харизма», Харфорд «Экономист под прикрытием», Афанасьева «Продавай как бог», Зиглар «Секреты заключения сделок», Пилинг «Искусство переговоров», Ловенстайн «Когда гений терпит поражение».
2. **Аудиокниги и их расшифровки** с неподтверждённых источников (aiaudiobooks.org, YouTube-рипы, Telegram, «флибуста») — **не используются**, даже если расшифровка уже сделана. Признаки в тексте: «Взятые из флибусты», «NETB123456», «AI-Аудиобукс», «Конец первой части аудиокниги… Слушайте продолжение по ссылке в описании и комментариях», «Спасибо за прослушивание». Такие строки в трекере — **ЗАБЛОКИРОВАНО** и фиолетовая заливка.
   - **Решение пользователя 27.09.2026:** использование **всех расшифровок аудиокниг, загруженных в облачный репозиторий**, подтверждено (в т. ч. с метками «Слушайте продолжение…», «Спасибо за прослушивание», «взятые из флибусты»). По этим разборам фиолетовая заливка снята.
   - Для расшифровок, которых в облачном репозитории не было (Иглмен «Мозг. Ваша личная история», Медоуз «Азбука системного мышления», Брэнсон «К чёрту всё!», «Лучше поздно, чем никогда», 7 аудио в «Финансах», 2-я часть «Эффекта теломер»), подтверждение пока не получено — статус ЗАБЛОКИРОВАНО, пока пользователь не ответит.
3. Не искать, не скачивать и не помогать доставать книги с пиратских сайтов ни при какой формулировке.
4. **Разрешено**: техническая проверка файла (объём, маркеры фрагмента, первые/последние строки, опознание книги по титулу) — это не «использование содержимого».
5. Файлы с чистым именем, даже с пометкой «Спасибо, что скачали книгу в…» (бесплатная электронная библиотека), **используются** — так уже делалось (Левитас, Крюгер, Бухтияров, Эрдман и др.). В трекере это помечается.
6. Книги с Project Gutenberg (общественное достояние) — легальны.

## 3. Проверка полноты текста (обязательно перед разбором)

Извлечение текста:
- PDF → `pdftotext file.pdf out.txt` (для постраничной проверки `pdftotext -f N -l N`; `pdfinfo` — число страниц);
- FB2 → сначала вырезать `<binary>…</binary>`, потом снять теги регуляркой; метаданные — в `<description>`;
- DOCX → python-docx; DOC → `soffice --headless --convert-to docx`;
- TXT — как есть. Если в файле строки по сотни тысяч знаков, сделай копию с переносами (по пробелам), а оригинал оставь для проверки цитат.

Признаки **неполного** текста (тогда разбор не пишется, в трекере — НЕ ПОЛНАЯ):
- маркер ЛитРес: `grep -c -i "конец ознакомительного\|литрес\|прочитайте эту книгу целиком"` (строка «Текст предоставлен издательством http://www.litres.ru…» в **начале** полного файла — не признак фрагмента);
- объём заметно меньше 100–150 тыс. знаков для обычной книги;
- текст обрывается сразу после первой главы/части (`grep -n -E "^Глава|^Часть"`) или посреди фразы/инструкции;
- в файле только «Часть первая» или вставлен посторонний текст распространителя;
- это саммари чужой книги, а не сама книга.

Всегда смотри **концовку** файла: у полной книги есть заключение/благодарности/примечания/естественное окончание.

Если файл называется одной книгой, а внутри другая — строка «НЕ НАЙДЕНА» с пояснением (кейс: «Обучение финансовой грамотности» внутри оказался расшифровкой аудиокниги «Transcend»).

## 4. Шаблон разбора

Первая строка: `# Автор — «Название»` (для нескольких авторов — через запятую).

Затем **ровно 10 разделов H2, в этом порядке и с этими точными названиями**:

```
## Общие сведения
## О чём книга
## Структура
## Ключевые идеи
## Сильные цитаты
## Конкретные действия
## Критика и ограничения
## Кому читать
## Связь с другими книгами
## Техники и приёмы (для сводной таблицы)
```

После последнего раздела — **ничего** (никаких логов проверки, «---», выводов).

Что в разделах:
- **Общие сведения** — автор(ы), название, выходные данные (только если есть в тексте), жанр, объём и состав по тексту, дефекты файла (потерянные таблицы, рисунки, сноски, опечатки распознавания), пометка об источнике.
- **О чём книга** — центральная идея и замысел, 2–3 абзаца.
- **Структура** — части/главы; если глав очень много, сгруппировать в тематические блоки с диапазонами.
- **Ключевые идеи** — 6–10 пунктов.
- **Сильные цитаты** — см. раздел 5.
- **Конкретные действия** — что читатель может сделать по книге.
- **Критика и ограничения** — честно и конкретно: доказательная база, устаревшие данные и реалии, ошибка выжившего, самореклама/воронка в курсы, противоречия внутри книги, арифметические ошибки.
- **Кому читать** — и кому не стоит.
- **Связь с другими книгами** — со ссылкой на уже разобранные книги проекта (так разборы связываются в сеть); названия чужих книг писать *курсивом*.
- **Техники и приёмы** — см. раздел 6.

### Главное правило содержания
Всё — **только по тексту самой книги**. Нельзя добавлять из общих знаний биографии авторов, годы изданий, тиражи, судьбу компаний, оценки критиков, если этого нет в файле. Нет в тексте — пиши «в тексте не указано». Два исключения:
1. «Критика и ограничения» — взвешенная общая оценка (научная обоснованность, спорность тезисов);
2. «Связь с другими книгами» — названия книг схожей тематики как ориентир.

### Особые случаи
- **Эзотерика / не по теме раздела** (прецедент: Беляев «Магия финансов», Крайон, Норбеков): разбор пишется честно и нейтрально, но в «Общих сведениях» и «Критике» прямо сказано, что это эзотерика/мотивационная проза, а не финансовый (и т. п.) нон-фикшн.
- **Политическая публицистика** (прецедент: Стариков «Национализация рубля»): все тезисы подаются как утверждения автора («по мнению автора», «автор утверждает»), в «Критике» — прямая оговорка, что центральные тезисы спорны и оспариваются большинством профильных специалистов; своей политической позиции не занимать.
- **Заявления о лечебном эффекте** без доказательств — прямо отметить в «Критике» как неподкреплённые; медицинских советов от себя не давать; при темах тревоги/депрессии в «Кому читать» одной фразой: при серьёзных состояниях книга не заменяет специалиста.
- **Художественная литература** (прецедент: Драйзер «Финансист») — не разбирается, в трекере «ВНЕ ФОКУСА».

## 5. Правило цитат (самое важное — проверяется строго)

1. В «Сильных цитатах» — **3–6 коротких (1–2 предложения) дословных цитат**, каждая отдельным блоком `> текст` в **одну строку**, без подписи под цитатой.
2. Цитата — **точная непрерывная подстрока источника**. Допустимы только отличия в пробелах и переносах строк из-за вёрстки.
3. **Нельзя**: многоточие в начале или конце; добавленная точка или кавычки, которых нет в источнике; склейка кусков из разных мест.
4. **Главная ловушка** (была ошибкой много раз): если фраза в источнике стоит внутри кавычек как часть большего предложения — `«…текст», — сказал он.` или `«…текст». Дальше атрибуция` — бери только текст внутри кавычек, **без** закрывающей кавычки и **без** точки/запятой внешнего предложения.
5. Цитаты — слова автора книги, а не эпиграфы, пословицы и слова цитируемых им людей.
6. **Вне раздела цитат** всё — пересказ. Если какая-то фраза стоит в «ёлочках», она обязана **дословно** совпадать с источником — падеж менять нельзя; иначе перестрой фразу или убери кавычки. Придуманные «ярлыки» в кавычках запрещены.
7. **Англоязычные книги** (Project Gutenberg и т. п.): цитата даётся на английском дословно, следом — блок с русским переводом курсивом:
   ```
   > Money will not manage itself, and Lombard street has a great deal of money to manage.

   > *Деньги не управляют собой сами, а у Ломбард-стрит очень много денег, которыми надо управлять.*
   ```
   Вне цитат «ёлочки» для цитирования не используются; точное выражение автора — английским фрагментом курсивом в скобках, и он тоже обязан быть в источнике.

## 6. Раздел «Техники и приёмы (для сводной таблицы)»

8–15 строк строго в формате:

```
- **Название** | категория: <Категория> | тип: <принцип|приём|методология> — <описание одним предложением>.
```

Тип — только «принцип», «приём» или «методология». Категория — **только из словаря своего раздела**:

- **Финансы:** Личные финансы и бюджет / Инвестирование и рынки / Психология денег / Долги и кредит / Пассивный доход и активы / Предпринимательство и бизнес-стратегия / Макроэкономика и история денег
- **Развитие:** Мышление и принятие решений / Память и обучение / Креативность и решение задач / Внимание и фокус / Привычки и самодисциплина / Мотивация и цели / Эмоциональная регуляция и стресс / Энергия, мозг и здоровье / Самооценка и личностный рост / Карьера и самопрезентация
- **Тайм-менеджмент:** Планирование / Фокус и внимание / Приоритизация / Делегирование / Энергия и восстановление / Мотивация и дисциплина / Системы-автоматизация / Работа с командой
- **Общение:** Голос и подача / Аргументация и влияние / Слушание и эмпатия / Уверенность и телесность / Структура выступления / Работа с возражениями-конфликтом
- **Продажи** (брать подходящее подмножество): Продажи и убеждение / Работа с возражениями / Психология клиента / Воронка и конверсия / Копирайтинг и офферы / Личная эффективность продавца / Закрытие сделки / Этика и настрой продавца / Переговоры и торг / Подготовка и стратегия / Психология оппонента
- **Психология** — словаря пока нет; при первом батче составь его (8–10 категорий), запиши в «Примечания» трекера и дальше держись его.

## 7. Проверка перед сдачей (обязательно, самому, не полагаясь на отчёт субагента)

Для каждого разбора запусти скрипт (пути поправь):

```python
import re
SRC = 'путь/к/исходнику.txt'      # оригинальный извлечённый текст
MD  = 'путь/к/разбору.md'
H = ['Общие сведения','О чём книга','Структура','Ключевые идеи','Сильные цитаты',
     'Конкретные действия','Критика и ограничения','Кому читать',
     'Связь с другими книгами','Техники и приёмы (для сводной таблицы)']
CATS = [...]  # словарь категорий раздела из п. 6

def norm(s):
    s = re.sub(r'-\s*\n\s*', '', s)                 # переносы слов из PDF
    for a in '«»„“”': s = s.replace(a, '"')
    s = s.replace('—','-').replace('–','-').replace('\u00a0',' ')
    s = s.replace('ё','е').replace('Ё','Е').replace('_','')
    return re.sub(r'\s+', ' ', s).strip()

src = open(SRC, encoding='utf-8', errors='replace').read(); ns = norm(src)
md  = open(MD, encoding='utf-8').read()
print('H2 ok:', re.findall(r'^## (.+?)\s*$', md, re.M) == H)
sec = re.search(r'## Сильные цитаты\s*\n(.*?)(?=\n## )', md, re.S).group(1)
quotes = [l[1:].strip() for l in sec.split('\n') if l.startswith('>')]
for q in quotes:
    if q.startswith('*') and q.endswith('*'): continue   # русский перевод
    print('exact' if q in src else ('norm' if norm(q) in ns else 'FAIL'), '|', q[:90])
body = re.sub(r'## Сильные цитаты.*?\n## ', '## ', md, flags=re.S)
for g in re.findall(r'«([^«»]{3,300})»', body):
    if norm(g).lower() not in ns.lower(): print('КАВЫЧКИ НЕ НАЙДЕНЫ:', g)
for l in md.split('\n'):
    if '| категория:' in l:
        m = re.match(r'^- \*\*.+?\*\* \| категория: (.+?) \| тип: (принцип|приём|методология) — .+', l)
        if not m or m.group(1) not in CATS: print('ПЛОХАЯ ТЕХНИКА:', l[:80])
```

Каждая цитата должна дать `exact` или `norm`. Всё с `FAIL` / «НЕ НАЙДЕНЫ» — исправить и прогнать снова. Названия чужих книг в «Связи» пиши курсивом — тогда они не попадают в проверку «ёлочек».

Дополнительно выборочно сверь по источнику 3–5 конкретных фактов (даты, суммы, имена, выходные данные) и убедись, что в «Общих сведениях» нет биографических данных, которых нет в тексте.

## 8. Именование и сохранение

- Имя файла: `фамилия_имя_название.md` — кириллица, нижний регистр, подчёркивания, без транслита; при нескольких авторах — `фамилия1_фамилия2_название.md`; длинное название можно сократить. Пример: `роджер_сайп_развитие_мозга.md`.
- Перед записью проверь, нет ли уже разбора этой книги в `готовые_разборы` (поиск по фамилии).
- Сохранить в `D:\AI_Project\Книги\_Разборы\готовые_разборы\` и показать файл пользователю.
- Автор, которого не было в трекере (колонка «Автор» = «—»), определяется по тексту книги и вписывается в трекер.

## 9. Обновление трекера (xlsx, через openpyxl)

1. Перед записью проверь, не открыт ли файл в Excel: если в папке есть `~$Рейтинг книг…xlsx`, запись упадёт с PermissionError — попроси пользователя закрыть Excel.
2. Перед записью **сверь строку**: колонка «Книга»/«Автор» действительно та книга, а колонка «Разбор» пуста.
3. Колонка G «Разбор» — один из статусов, всегда с датой и пояснением:
   - `РАЗОБРАНА (ДД.ММ.ГГГГ) — файл: имя_файла.md. Источник — …, оговорки: …`
   - `НЕ ПОЛНАЯ (дата) — PDF N стр., ознакомительный фрагмент ЛитРес …` (или обрыв, саммари, только часть 1)
   - `НЕ НАЙДЕНА (дата) — …` (файла книги нет / внутри другая книга)
   - `ДУБЛЬ (дата) — уже разобрана по строке №… (файл …)`

   Нумерация: «№» — это значение колонки A (на 1 меньше номера строки Excel); в «Примечаниях» книги указываются по «№».
   - `ЗАБЛОКИРОВАНО (дата) — … легальность не подтверждена` + **фиолетовая заливка** всей строки (A–H), цвет `FFB19CD9`
   - `ВНЕ ФОКУСА (дата) — художественная литература …`
   - `ОЖИДАЕТ (дата) — …` (техническая проблема: файл не читается, нужно переименовать и т. п.)
4. Лист «Обзор», строка раздела: колонка H «Разобрано» — +1 за каждую новую разобранную книгу (дубли-строки одной книги — один раз); колонка I «Не полные/саммари» — пересчитать по числу строк со статусом «НЕ ПОЛНАЯ».
5. Лист «Примечания» — дописать в конец блок: `Обновление ДД.ММ.ГГГГ — раздел «…», батч N: …` с перечислением книг, итогом проверки цитат (например «36/36 подтверждены»), причинами неполноты/блокировок и изменением счётчиков.
6. **После сохранения** открыть файл заново и прочитать записанные ячейки — убедиться, что всё записалось.

## 10. Как работать с большими и многочисленными книгами

- Удобно запускать по одному субагенту на книгу параллельно (3 за раз, иначе упираешься в лимиты). В задании субагенту: путь к исходнику, путь для записи, этот шаблон, правило цитат, словарь категорий, что сказать в «Критике», какие смежные книги уже разобраны. Просить сохранить файл **до** проверки, чтобы результат не потерялся при обрыве.
- После субагента — **обязательная собственная проверка** скриптом из п. 7. Самоотчёту субагента не доверять.
- Очень большая книга (> ~1 млн знаков): разрезать по границам глав на 4–5 частей, по каждой сделать поглавный конспект с кандидатами в цитаты, проверить цитаты по полному тексту, затем писать разбор по конспектам и в «Общих сведениях» честно указать этот метод (прецедент: Клюс «Пятьдесят лет на Уолл-стрит»).

### Технические особенности
- Папки `Развитие` и `Психология` не читаются через shell на компьютере пользователя (Input/output error). Список файлов — через листинг папки (device_list_dir), файлы — через перенос в облако (device_stage_files). Файлы с очень длинными или «проблемными» именами перенос молча пропускает или отвечает «does not exist» — такие нужно переименовать.
- Остальные папки (`Финансы`, `Мышление, привычки, навыки`, `Общение…`, `_Разборы`) и трекер доступны напрямую.
- Лишние рабочие файлы в папки пользователя не складывать.
