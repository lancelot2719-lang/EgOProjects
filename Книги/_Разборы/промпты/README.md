# Комплект промптов для разбора книг (улучшенный)

Версия: 2.0. Улучшения по четырём уровням — A, B, C, D.

## Состав

| Файл | Уровень | Назначение |
|------|---------|-----------|
| `УРОВЕНЬ-A_основной.txt` | A | Один проход, но с жёстким фактчекингом: дословные цитаты, источники [], запрет выдумывания, проверяемость |
| `УРОВЕНЬ-B1_структура.txt` | B | Шаг 1 multi-pass: извлечение структуры (части, главы, дословные названия) |
| `УРОВЕНЬ-B2_идеи.txt` | B | Шаг 2 multi-pass: 12-14 ключевых идей с конкретикой и источниками |
| `УРОВЕНЬ-B3_цитаты.txt` | B | Шаг 3 multi-pass: дословные цитаты с проверкой |
| `УРОВЕНЬ-B4_агрегация.txt` | B | Шаг 4 multi-pass: сборка финального разбора из трёх проходов |
| `УРОВЕНЬ-C_верификация.txt` | C | Шаг 5: независимая проверка разбора второй моделью (LLM-as-judge) |
| `УРОВЕНЬ-D_rag_вопросы.txt` | D | Режим RAG: ответы на вопросы по релевантным фрагментам вместо случайных срезов |

## Как использовать

### Вариант 1. Быстрый (уровень A) — один проход
Берёшь `УРОВЕНЬ-A_основной.txt`, заменяешь `{Автор}`, `{Название}`, `{ТЕКСТ}` — и гонишь через любую модель (Ollama, OpenCode, NotebookLM).

Подходит для: быстрых разборов, книг среднего размера, когда важна скорость.

### Вариант 2. Точный (уровни A + B + C) — multi-pass пайплайн
Рекомендуемый режим для важных книг:

1. **B1** — выжимку книги → модель → получаешь структуру.
2. **B2** — ту же выжимку → модель → получаешь идеи.
3. **B3** — ту же выжимку → модель → получаешь цитаты.
4. **B4** — все три результата → модель → получаешь финальный разбор.
5. **C** — финальный разбор + текст книги → ВТОРАЯ модель (другая, например mistral) → отчёт о достоверности.

Почему так: каждая модель-проход фокусируется на одной задаче и не «размазывается». Верификация второй моделью ловит выдуманные цитаты и приписанные идеи.

Можно гнать B1, B2, B3 параллельно — они не зависят друг от друга.

### Вариант 3. Максимальная точность (уровни A + B + C + D) — с RAG
Вместо случайных срезов текста — семантический поиск:
1. Заиндексируй книгу в векторную базу: `python projects/knowledge-base/rag-indexer.py` (книга в `books_raw/`).
2. По каждому разделу будущего разбора сформулируй 5-10 вопросов (они в `УРОВЕНЬ-D_rag_вопросы.txt`).
3. Для каждого вопроса получи топ-5 фрагментов через `rag-query.py`.
4. Промптом D отвечай на вопросы по фрагментам.
5. Собери разбор из ответов (можно через B4).

## Оценка качества

После каждого разбора запускай `УРОВЕНЬ-C_верификация.txt` и фиксируй:
- сколько цитат прошло дословную проверку;
- сколько фактов оказалось выдуманными;
- сколько идей приписано автору ложно.

Это даёт объективную метрику и показывает, какая модель точнее для ваших книг.
