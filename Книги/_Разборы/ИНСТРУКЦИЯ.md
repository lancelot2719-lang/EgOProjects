# Как доделать оставшиеся 19 разборов

Готово уже 11 разборов — они лежат в папке `готовые_разборы`. Осталось 19 книг,
их тексты подготовлены в папке `тексты_для_NotebookLM`.

Ниже два способа. Можно комбинировать: что-то через NotebookLM, что-то локально.

---

## Способ 1. NotebookLM (рекомендую — качество максимальное)

Почему именно он: NotebookLM загружает книгу целиком и строит поиск по всему тексту.
Claude в облаке видит только выжимку (начало плюс срезы), поэтому по подробностям
NotebookLM здесь объективно сильнее.

Порядок действий для каждой книги:

1. Откройте https://notebooklm.google.com и создайте новый блокнот.
2. Нажмите «Добавить источник» и загрузите ОДИН файл из папки `тексты_для_NotebookLM`.
3. Откройте файл `ПРОМПТ_для_NotebookLM.txt`, скопируйте весь текст.
4. Вставьте промпт в чат блокнота. В первой строке замените `{Автор}` и `{Название}`
   на реальные — они есть в имени файла и в списке ниже.
5. Дождитесь ответа, скопируйте его целиком.
6. Сохраните ответ в папку `новые_разборы` под тем же именем, что у исходного файла,
   но с расширением `.md`.

Например: загрузили `Дахигг_Сила_привычки.txt` → сохраняете ответ как
`новые_разборы/Дахигг_Сила_привычки.md`.

Важно: делайте по одной книге на блокнот. Если загрузить несколько книг в один блокнот,
модель начнёт смешивать источники, и появится тот самый шум.

---

## Способ 2. Локально через opencode + Ollama (бесплатно, без лимитов)

У вас уже установлены opencode и Ollama. В отличие от облака, opencode работает прямо
на Windows, поэтому видит и папку с книгами, и Ollama на localhost.

В папке `скрипты` лежит `разбор_через_ollama.py`. Запуск:

```
ollama serve
ollama pull qwen2.5:14b-instruct
python скрипты\разбор_через_ollama.py
```

Скрипт сам пройдёт по всем текстам из `тексты_для_NotebookLM`, прогонит их через
локальную модель и разложит результат в `новые_разборы`.

Честное предупреждение: на 12 ГБ видеопамяти модель уровня 14B по русскому
аналитическому тексту будет заметно слабее NotebookLM и Claude — больше общих фраз,
меньше конкретики. Для книг из середины списка приемлемо, для важных лучше NotebookLM.

## Способ 3. Определить неопознанные файлы (задача как раз для Ollama)

В библиотеке есть файлы с нечитаемыми именами: `1.pdf`, `56786282.pdf`,
`ff06f7b7-58e6-4f4c-bb7f-ce70c3215497.pdf` и подобные. Непонятно, что это за книги.

Скрипт `скрипты\опознать_книги.py` берёт первую страницу каждого такого файла и просит
локальную модель определить автора и название. Задача простая, локальная модель
справляется хорошо, а нам это закроет пробелы в каталоге.
