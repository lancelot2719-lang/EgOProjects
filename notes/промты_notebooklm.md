# Промты для NotebookLM — анализ книг

## Структура использования

1. Открываешь NotebookLM, создаёшь новый Notebook
2. Загружаешь PDF книг в Sources
3. Вставляешь нужный промт в чат
4. После ответа используешь кнопку **"Add to notes"** для сохранения результата

---

## 1. Универсальный промт для анализа одной книги

Скопируй это в чат после загрузки книги:

```
## РОЛЬ

Ты — профессор и исследователь, специализирующийся на данной теме. Твоя задача — провести максимально глубокий анализ книги.

## ИНСТРУКЦИЯ ПО АНАЛИЗУ

Проанализируй загруженную книгу по следующей структуре. Каждый пункт обязателен.

### 1. КОНЦЕПТУАЛЬНАЯ КАРТА КНИГИ
Какую главную проблему решает книга? Какова центральная идея? Нарисуй логическую схему: проблема → причины → решение → результаты. Выдели не более 5 ключевых концептов и свяжи их между собой.

Для каждого концепта укажи:
- **Определение** (что это, простыми словами)
- **Механизм** (как это работает, почему это работает именно так)
- **Связь с другими концептами** (что из чего вытекает)

### 2. КЛЮЧЕВЫЕ ИДЕИ (максимум 10)
Для каждой идеи:
- Формулировка (1 предложение)
- Почему это важно / в чём новизна
- Конкретный пример из книги
- Контринтуитивность (если есть): что в этой идее противоречит общепринятому мнению

### 3. ПРАКТИКА: ИНСТРУКЦИИ, ЛАЙФХАКИ, ТЕХНИКИ
Извлеки все практические инструменты из книги. Для каждого:
- **Название техники**
- **Пошаговая инструкция** (как применить)
- **Когда применять** (в каких ситуациях)
- **Ожидаемый результат**
- **Возможные ошибки** (что может пойти не так и как это предотвратить)

### 4. ПРИНЦИПЫ И ПРАВИЛА
Сформулируй все принципы, которые автор вводит или на которые опирается. Примеры:
- «Концентрация на одном деле даёт лучший результат, чем многозадачность»
- «Лучше меньше, но качественнее»

### 5. НАУЧНАЯ БАЗА (если есть)
- На какие исследования, эксперименты, данные ссылается автор?
- Насколько эти источники авторитетны?
- Есть ли более свежие исследования, опровергающие или подтверждающие?

### 6. СИЛЬНЫЕ И СЛАБЫЕ СТОРОНЫ КНИГИ
- Что в книге действительно ценно и уникально?
- Какие аргументы кажутся слабыми или спорными?
- Какие темы автор обошёл стороной?
- Есть ли конфликт интересов или предвзятость?

### 7. ВЫВОД: ЧТО ДЕЛАТЬ ЗАВТРА
- 3 самых важных действия, которые я должен сделать после прочтения
- 1 ошибка, которую я должен перестать совершать
- 1 привычка, которую стоит внедрить

### 8. ОЦЕНКА КАЧЕСТВА ОТВЕТА
В конце укажи для каждого раздела уровень уверенности (1-10). Если какие-то части основаны на предположениях — отметь это.
```

## 2. Промт для сравнения нескольких книг

Загрузи 2-5 книг в Sources, затем вставь это:

```
## РОЛЬ

Ты — научный редактор, который проводит систематический обзор литературы по заданной теме. Твоя задача — не просто сравнить книги, а синтезировать из них единую картину знаний.

## ИНСТРУКЦИЯ ПО СРАВНЕНИЮ

Проанализируй все загруженные книги. Для каждой указывай название. В конце синтезируй итоговый вывод.

### ШАГ 1: СВОДКА ПО КАЖДОЙ КНИГЕ (кратко)

Для каждой книги из источников:
- **Основной тезис** (1 предложение)
- **Ключевой метод/решение**, которое предлагает автор
- **Целевая аудитория** (для кого написана)
- **Уникальный вклад** (чем эта книга отличается от других в подборке)

### ШАГ 2: КОНЦЕПТУАЛЬНОЕ СХОДСТВО

Найди идеи, концепции и выводы, которые повторяются у всех (или большинства) авторов.

Для каждой общей идеи:
- Формулировка идеи
- В каких книгах встречается
- Пример формулировки из каждой книги (цитата или пересказ)
- Почему эта идея консенсусная (есть ли научное объяснение)

### ШАГ 3: РАЗНОГЛАСИЯ И ПРОТИВОРЕЧИЯ

Найди точки, где авторы расходятся. Для каждого расхождения:

- **Вопрос / тема расхождения** (например, «нужно ли делать сбережения до инвестиций?»)
- **Позиция 1** — автор(ы), аргументы, обоснование
- **Позиция 2** — автор(ы), аргументы, обоснование
- **Промежуточные позиции**, если есть
- **Почему возникло расхождение** — это важно. Возможные причины:
  * Разные контексты написания (дата, страна, аудитория)
  * Разные личные убеждения авторов
  * Разные исходные данные / исследования
  * Разные определения терминов
  * Ошибка или предвзятость одного из авторов

### ШАГ 4: ДОПОЛНЕНИЕ ВНЕШНИМИ ЗНАНИЯМИ

Теперь примени знания, выходящие за рамки этих книг:

- Какие современные исследования (последние 5 лет) подтверждают или опровергают идеи из книг?
- Какие практические кейсы из реальной жизни (бизнес, наука, повседневность) иллюстрируют описанные принципы?
- Есть ли культурные или региональные различия, которые влияют на применимость идей?
- Какие альтернативные подходы существуют, но не упомянуты в книгах?

Для каждого дополнения чётко укажи источник: «исследование Nature 2024», «кейс компании X» и т.д.

### ШАГ 5: СИНТЕЗ — ИТОГОВАЯ КАРТИНА

Создай единую интегрированную модель знаний по теме:

- **Безусловные истины** (в чём авторы и современная наука единодушны)
- **Рабочие гипотезы** (что выглядит обоснованно, но требует проверки)
- **Открытые вопросы** (где до сих пор нет ясности и почему)
- **Практический алгоритм** — пошаговая инструкция, объединяющая лучшее из всех книг

### ШАГ 6: РЕКОМЕНДАЦИЯ

- Какую книгу читать первой, если времени мало?
- Какие главы/разделы можно пропустить?
- Какие книги стоит дополнительно изучить по смежным темам?

### ШАГ 7: ОЦЕНКА УВЕРЕННОСТИ

Укажи для каждого шага уверенность (1-10). Отметь, какие части основаны на книгах, а какие — на внешних данных или предположениях.
```

## 3. Быстрый промт (экспресс-анализ)

Когда нужно быстро, без полного разбора:

```
Ты — профессиональный рецензент. Проанализируй книгу по трём слоям:

1. **Содержание:** Главная идея, 5 ключевых тезисов, 3 практических инструмента.
2. **Критика:** Что в книге действительно ценно, а что слабо обосновано? Где автор противоречит себе?
3. **Применение:** Что конкретно я могу взять и использовать завтра?

Формат ответа:
### Основная идея
### 5 тезисов
### 3 инструмента
### Критика
### Действия
### Уверенность (1-10)
```

## 4. Промт для поиска по библиотеке

Когда загружено много книг и нужно найти что-то конкретное:

```
Проведи поиск по всем загруженным источникам. Мне нужно найти:

- Все инструменты и техники, связанные с [тема]
- Все аргументы авторов ЗА и ПРОТИВ [идея]
- Все исследования/эксперименты, упомянутые в книгах по [тема]

Для каждого найденного элемента укажи:
1. Название книги и автора
2. Краткую суть (1-2 предложения)
3. Страницу или раздел (если известно)

Результат оформи как структурированный список, сгруппированный по книгам.
```

## Заметки по использованию

- NotebookLM под капотом Gemini — он хорошо держит контекст, можно загружать книги до 500+ страниц
- После получения ответа нажимай **"Pin"** или **"Add to notes"** — это сохранит результат в блокноте
- Для нового раунда анализа используй тот же блокнот, добавляя новые источники
- Источники можно группировать по темам (отдельный Notebook на тему: «Финансы», «Психология», «Продажи»)
- Аудиообзоры (Audio Overview) работают на основе текущих источников и заметок — полезно для повторения
