# business — Карта папок

```
business/
├── INDEX.md       ← этот файл, карта раздела
├── products/      ← описания продуктов, УТП, позиционирование
├── audience/      ← портреты клиентов, сегменты, боли
├── goals/         ← цели (месяц, квартал, год) и ключевые результаты
├── economics/     ← цены, скидки, маржинальность, финансовые модели
└── marketing/     ← гипотезы, каналы, скрипты, A/B-тесты
```

## Назначение
Вся бизнес-информация в одном месте. Каждое решение, каждая гипотеза, каждый вывод по продукту или клиенту фиксируется здесь. Агент использует этот раздел, чтобы предлагать релевантные решения в контексте твоего бизнеса.
